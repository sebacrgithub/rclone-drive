rclone — configurazione personale

Questa applicazione OAuth viene utilizzata da Sebastiano per collegare il proprio account Google Drive a una macchina virtuale Oracle Linux tramite rclone.

La configurazione permette di consultare, scaricare, creare, modificare ed eliminare file e cartelle del proprio Drive. Il montaggio viene condiviso con il proprio computer Windows tramite una condivisione Samba autenticata.

L'autorizzazione viene concessa dal titolare attraverso Google. Questa pagina non effettua l'accesso all'account e non contiene i file di Drive.

Si tratta di una configurazione personale del software open source rclone, indipendente da Google e dal progetto rclone.
