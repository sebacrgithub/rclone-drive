Informativa sulla privacy

Configurazione personale di rclone · Aggiornata il 4 novembre 2026

Gestore e finalità

La configurazione è gestita da Sebastiano per accedere ai file del proprio account Google Drive da una macchina virtuale Oracle Linux e dal proprio computer Windows. Non è un servizio destinato al pubblico.

Dati consultati e operazioni

Su autorizzazione del titolare, rclone accede ai nomi, ai metadati e ai contenuti dei file e delle cartelle di Google Drive. Le autorizzazioni concesse consentono di elencare, leggere, scaricare, caricare, creare, modificare ed eliminare tali elementi per eseguire le operazioni richieste dal titolare.

Conservazione

I file originali sono conservati su Google Drive. La macchina virtuale conserva la configurazione OAuth, compresi i token necessari all'accesso, e una cache locale dei file consultati o modificati. I file scaricati sul computer Windows rimangono sul computer finché non vengono eliminati. I log tecnici possono contenere nomi dei file, percorsi ed errori.

Accesso e condivisione

I file possono essere letti o modificati dai dispositivi autorizzati attraverso la condivisione Samba e sono trasferiti a Google per le operazioni su Drive. Questa configurazione non è destinata alla vendita dei dati, alla pubblicità o all'addestramento di modelli di intelligenza artificiale. L'utilizzo dei dati ottenuti tramite le API Google è limitato alle finalità descritte e rispetta la Google API Services User Data Policy, inclusi i requisiti Limited Use.

Revoca ed eliminazione

Il titolare può revocare l'accesso dalla pagina delle connessioni del proprio account Google. La revoca interrompe le future richieste autorizzate e non elimina automaticamente le copie locali. Dopo aver interrotto i trasferimenti e verificato il completamento delle scritture, il titolare può eliminare configurazione, token, cache e copie locali dai propri dispositivi. I file su Drive si gestiscono separatamente dal proprio account Google.

Questo sito

Queste pagine statiche non richiedono l'accesso a Google, non leggono i file di Drive e non includono strumenti di analisi o script di tracciamento. Il fornitore di hosting GitHub può trattare dati tecnici di navigazione secondo la propria informativa privacy.
